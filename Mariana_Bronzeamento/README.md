# Mariana Barbosa — Bronzeamento Natural

Landing page estática em Astro, Tailwind CSS e componentes baseados em shadcn/ui. Os agendamentos direcionam para o WhatsApp da Mariana.

## Comandos

```bash
bun install
bun astro dev --background
bun run build
```

Para encerrar ou acompanhar o servidor de desenvolvimento:

```bash
bun astro dev status
bun astro dev logs
bun astro dev stop
```

O site é gerado estaticamente. Fotos de resultado e ambiente ficam em `public/images/`; substitua as imagens atuais pelas fotos aprovadas da Mariana antes da publicação.
